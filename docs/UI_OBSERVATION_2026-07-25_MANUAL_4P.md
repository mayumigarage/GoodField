## 5. 実装へ反映する規範

1. 悪魔カード・対象・効果値を1,000ms表示する。
2. 続いて中央のダメージ表示を1,000ms保持する。
3. HP0となる場合、次の表示状態で「昇天」とHP0を同時に反映する。
4. 昇天だけではGF値を増やさない。
5. 操作プレイヤーが昇天しても、生存者が2人以上なら結果画面へ進まない。
6. 本人の手札を残し、ゲーム入力だけを無効化して観戦へ移る。

## 6. 計測上の注意

- DOM表示の75msポーリングによる計測のため、境界には最大約75msの誤差がある。
- 操作者の入力待ち時間を含むGF間隔は、固定演出時間の根拠にしない。
- 反射・弾き、複数回・全体攻撃、守護神、最終結果画面はこの試合の昇天までに十分な標本を得ていない。
