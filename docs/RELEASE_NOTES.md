# GoodField 0.1.0 リリースノート

リリース判定日: 2026-07-26

## 対象

- 2026-07-24時点のゴッドフィールド現行Web版を互換基準とする。
- Web版、2～9人の個人戦を対象とする。
- ルールセットは`GOODFIELD_RULESET_2026_07_25`、カードプールは
  `OFFICIAL_WEB_2026_07_24`へ固定する。
- サーバー正本、シード付き決定論、プレイヤー別秘匿投影、再接続、CPU代行、
  レスポンシブ対戦画面を含む。

## 品質確認

- 9人CPU戦、終末悪魔連鎖、512段の反射連鎖を負荷試験する。
- 切断・再接続、イベント欠落、重複配信を障害注入試験する。
- Actor偽装、他人のカードID、不正対象、MP改ざん、過大入力、過剰頻度を拒否する。
- WebSocket接続では認証主体から参加プレイヤーまたは認可済み観戦者を決定する。
- 公開ペイロードにシード、PRNG状態、乱数ログ、内部キューを含めない。

## 既知の差異と初回リリース範囲外

- チーム戦の勝敗表示とチーム専用UIは対象外。
- 2026-07-24以降の公式ルール変更へ自動追随しない。
- 反射・弾き、守護神などの未計測の固有演出時間は共通500ms段階を使用する。
- 昇天後に退出したプレイヤーの観戦再参加は保証しない。
- 4～9人のモバイル縦画面は横スクロールを使用し、専用配置は対象外。
- カスタムカードと標準外タイミングは対象外。
- 公式実装のPRNG列そのものではなく、確率、処理順、結果の互換を対象とする。

これらはゲーム進行を停止する未解決事項ではなく、実装規則を固定した上での
公式版との差異または明示的な対象外である。
