## 1. 実装前提

### 完了条件の共通定義

各実装タスクは、次をすべて満たした時点で完了とする。

- 実装と自動テストが追加されている。
- 同一シード、同一初期状態、同一コマンド列で結果とイベント列が一致する。
- クライアント入力を信用せず、サーバー側で合法性を再検証する。
- 非公開情報が他プレイヤーや観戦者へ配信されない。
- 仕様から外れる判断がある場合、理由と採用ルールが文書化されている。

### 優先度

- `P0`: 後続実装の前提、または最初のプレイアブル版に必須
- `P1`: ルール互換版の完成に必須
- `P2`: リリース品質、運用性、追加互換性のために必要
