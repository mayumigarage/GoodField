# GoodField 0.1.0 リリース判定

判定日: 2026-07-26

## 判定

初回リリース範囲（Web版、2～9人個人戦）についてリリース可とする。
判定コマンドは`npm run release:check`であり、生成物、型、lint、全自動テスト、
タスク完了状態、必須運用文書を検査する。

## 自動確認

- 決定論、冪等性、秘匿、再接続、E2E、ゴールデンFixture
- 9人戦、終末悪魔連鎖、反射連鎖の時間・CPU・メモリ・イベント・通信量計測
- 切断、イベント欠落、重複配信からの完全または差分同期
- HTTP/WebSocketの認証・認可、入力スキーマ、サイズ、レート制限
- 2、4、9人表示と64rem/44remのレスポンシブ境界
