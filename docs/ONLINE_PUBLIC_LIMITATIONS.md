# 招待制オンライン版の利用条件

更新日: 2026-07-26

- 1ルームは2～9席、個人戦のみ。HumanとCPUを混在できる。
- ホストが発行した招待URLを知る利用者だけが参加できる。公開マッチメイキング、
  恒久アカウント、課金、ソーシャルログインには対応しない。
- 観戦はホストがルーム作成時に許可した場合だけ利用できる。
- 操作期限は15秒。期限切れまたは切断時はCPUが代行し、再接続だけではHuman操作へ
  戻らない。
- 未開始ルームは作成から2時間、終了・失効したルームと試合ジャーナルは24時間保持し、
  その後削除する。匿名の運用メトリクスは30日保持する。
- 障害時は新しいコマンドや参加を一時停止し、画面の再試行案内に従って同じブラウザから
  再接続する。招待URLや再参加情報を公開のチャットや画面共有へ載せない。
- 初期運用は単一リージョンであり、リージョン全体の障害中は新規対戦を開始できない。
